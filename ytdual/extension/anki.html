Anki 내보내기

폰에서 저장한 문장을 데스크톱 Anki로 보냅니다. Anki가 실행 중이어야 합니다.

    AnkiConnect가 연결되지 않을 때

    Anki → 도구 → 부가기능 → AnkiConnect → 설정에서 webCorsOriginList에 이 페이지의 주소를 추가하세요. 주소창에 보이는 moz-extension://... 의 앞부분입니다. 예:

    { "webCorsOriginList": ["http://localhost", "moz-extension://여기에-uuid"] }

    추가한 뒤 Anki를 재시작해야 적용됩니다.
